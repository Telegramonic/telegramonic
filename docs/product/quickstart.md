# Quick Start Guide

Get up and running with Telegramonic in minutes. Follow these simple steps to configure your credentials and launch the dashboard.

## Prerequisites

Before starting, make sure you have:
1. A valid Telegram account.
2. Custom API credentials (API ID and API Hash) from [my.telegram.org](https://my.telegram.org).

## Step 1: Configuration

When you first launch the app, you will be prompted for your API configuration:

1. Enter your **API ID** (e.g., `28123456`).
2. Enter your **API Hash** (e.g., `d58a9e...`).

## Step 2: Verification

After saving your API credentials, enter your phone number in international format (e.g., `+1 555-0199`).
Telegramonic will request a verification code from Telegram:

- Check your active Telegram app sessions for the login code.
- Enter the code in the workspace prompt to establish a secure session.

## Step 3: Accessing the Dashboard

Once authenticated, your session is securely encrypted locally. You can immediately access:
- File uploads.
- Drive statistics.
- Shared link generators.
